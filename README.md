# OceanCrest AI tri-fold

Interactive 3D preview of the OceanCrest AI tri-fold brochure, with the print-ready PDF.

- `index.html`: the 3D viewer. Drag to spin, use the slider to fold, or press Play tour.
- `OceanCrest-AI-Trifold.pdf`: two-sided letter sheet (11 x 8.5 in), roll-folded into three panels.
- `assets/3d/`: the six panel images the viewer folds.
